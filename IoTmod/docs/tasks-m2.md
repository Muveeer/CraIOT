# M2 — реальные ESP32

- [x] Отказ от симулятора как обязательной части M2; источник данных — реальный MQTT-трафик ESP32.
- [x] Автоматический HELLO после успешного connect+subscribe и ручная HELLO-кнопка.
- [x] Разбор протокола через `org.json` без новых зависимостей и плагинов.
- [x] Application-scoped in-memory реестр устройств и виджетов.
- [x] Обработка `/state`, announce, `/config`, hide-by-id, `/status`, `/event` и входящего `/control`.
- [x] Объединение status-значения и status-info; создание stub-виджетов до получения конфига.
- [x] Экспорт последних 500 отфильтрованных сообщений журнала.
- [ ] Проверка на реальном парке ESP32: конфиги, merge, поворот экрана и восстановление после фонового disconnect.
- [ ] Проверка `./gradlew test`.

Room, история и графики перенесены в M4. Конфиги устройств восстанавливаются повторным HELLO после reconnect.
