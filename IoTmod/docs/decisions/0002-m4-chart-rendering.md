# ADR 0002: Canvas-рендер графиков для M4

- Статус: принято
- Дата: 2026-11-22

## Решение

Графики IoTmod реализуются собственным Canvas-рендером Compose, без Vico.

## Причины

- В приложении используется Compose 1.7.6; в выбранном объёме M4 не требуется зависеть от дополнительного графического API.
- Собственный рендер даёт прямой контроль над несколькими сериями, тёмной темой, осями, тултипом и downsample envelope.
- История хранится в Room и не зависит от библиотеки отображения. При необходимости Vico можно подключить позднее без миграции данных.

## Последствия

- Рендер и интерактивность графика поддерживаются внутри IoTmod.
- История в Room остаётся источником данных и не меняет формат при замене визуализации.
